Tools used to build and maintain the app

pnpm installs dependencies reproducibly. Vite/electron-vite builds the code and refreshes it during development. TypeScript, ESLint, and Prettier check and organize the source.

Vitest checks approval, cache, and resume rules. React Testing Library checks the review interface. Playwright exercises desktop flows. electron-builder packages Windows releases. Git records changes; GitHub Actions, if adopted, repeats checks in CI.

The production UI is planned in React/TypeScript. This standalone illustration uses plain JavaScript and mocked data so it opens without installing dependencies.
